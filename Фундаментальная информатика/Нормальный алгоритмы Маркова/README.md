# Отчёт по лабораторной работе №4 по курсу "Фундаментальная информатика"

**Тема:** Программирование в алгоритмической модели Маркова.

**Цель:** Освоить принципы программирования в алгоритмической модели Маркова (НАМ). Реализовать алгоритм кодирования строки по шифру Цезаря.			

**Задание:** Разработать алгоритм Маркова, выполняющий кодирование входного слова по шифру Цезаря.
> [!NOTE] 
> **Вариант №32**:
> Входное слово представляет собою последовательность латинсĸих буĸв, за ĸоторой следует двоичное
> число. Составить алгоритм ĸодирования первого слова по ĸоду Цезаря с ĸлючом, равным второму слову.

## Идея и метод решения
Ключевая идея заключается в следующем:
- Двоичное число, идущее после слова, переводится в унарный вид путём последовательного декремента
- Каждая единица унарного счётчика соответствует одному применению сдвига по шифру Цезаря

Таким образом, задача сводится к двум основным подзадачам:
1. Вычитание единицы из двоичного числа (перевод в унарный вид)
2. Реализация одного шага циклического сдвига букв латинского алфавита

> [!IMPORTANT]
> Дополнительное разделение входных данных не требуется, т. к. буквенная часть и двоичное число изначально разделены пробелом.


## Алгоритм

> [!NOTE]
> **Используемые маркеры:**
> - `[` – найти конец двоичного числа (чтобы начать отнимать)
> - `!` – конец двоичного числа найден!
> - `<`, `>` – маркеры, используемые для декремента
> - `X` – унарная единица
> - `F` – конец унарного числа
> - `#` – используется для стирания двочиного числа, равного нулю
> - `]` – используется для стирания оставшихся маркеров, после выполнения задачи

### 1. Перевод двоичного числа в унарный вид
Двоичное число обрабатывается с конца. На каждом шаге из него вычитается единица с учётом возможного заёма.  
Каждый успешно выполненный декремент соответствует одной итерации будущего сдвига и фиксируется с помощью служебных маркеров.

Этот этап продолжается до тех пор, пока двоичное число не станет равным нулю, после чего двоичное представление стирается.
> ИТОГ: a..zXX..XXF

### 2. Единичный сдвиг по коду Цезаря
Один шаг сдвига реализован с помощью набора правил вида:
```
aX->Xb
bX->Xc
...
zX->Xa
```

Маркер `X` перемещается вдоль слова, последовательно заменяя каждую букву на следующую по алфавиту с циклическим переходом `z -> a`.
> a..yXaX...
Таким образом, маркеры `X` переходят из правой части строки в левую.

### 3. Циклическое повторение сдвига
> [!NOTE]
> Циклическое применение сдвига не реализуется в виде отдельного управляющего этапа.  
> Повторение возникает естественным образом за счёт устройства НАМ.

Пока унарный счётчик (правая часть строки) содержит хотя бы одну единицу, алгоритм переходит к выполнению следующей итерации шага 2.  
После полного исчерпания унарного счётчика соответствующие правила становятся неприменимыми, и алгоритм автоматически переходит к завершающему этапу очистки ленты _(шаг 4)_.
> ИТОГ: XX..Xab..zF

### 4. Завершение и очистка
После того, как все маркеры `X` были переведены в левую часть строки, маркер `F` превращается в маркер `]`, который проходит справа-налево, стирая оставшиеся маркеры `X`.
"Встречая" пустоту, маркер `]` стирается и завершает выполнение алгоритма (`]->.`). На ленте остаётся только закодированное слово.

В ходе выполнения данной лабораторной работы было освоено на практике программирование НАМ.

Ключевым результатом работы стало понимание того, что управление вычислениями в НАМ достигается не за счёт явных циклов или счётчиков,
